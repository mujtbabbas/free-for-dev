# Reader's Guide — free-for-dev

## What this project is

**free-for-dev** is a list of **services with free tiers that matter to
developers and infrastructure engineers** — cloud platforms, CI, monitoring,
email, hosting and dozens of other categories. The editorial rule that makes
the list useful: free tiers are getting rarer, so entries focus on tiers that
are genuinely useful for hobbyists and small teams, not 14-day trials.

## How the content is organised

Everything lives in [`README.md`](README.md) — a very large file (this guide
was written from its section outline and the repository tree) with one
section per category, 58 in all. The main areas:

- **Cloud & hosting:** Major Cloud Providers, Cloud management solutions,
  PaaS, BaaS, IaaS, Web Hosting, DNS, Domain, CDN and Protection.
- **Build & ship:** Source Code Repos, Artifact Repos, CI and CD, Code
  Generation, Code Quality, Code Search and Browsing, Testing, Package Build
  System, IDE and Code Editing, Docker Related.
- **Data & backend:** APIs, Data, and ML, Managed Data Services, Messaging
  and Streaming, Storage and Media Processing, Search.
- **Operations:** Monitoring, Log Management, Crash and Exception Handling,
  Analytics, Events and Statistics, Visitor Session Recording.
- **Product & team:** Tools for Teams and Collaboration, CMS, Authentication
  Authorization and User Management, Email, Forms, Feature Toggles,
  Translation Management, Payment and Billing Integration, Design and UI,
  Education and Career Development, Generative AI, and a Miscellany
  (Miscellaneous, Other Free Resources).

Supporting files: `index.html` — the list rendered as a website (with
`CNAME` for its custom domain), `CONTRIBUTING.md` — the inclusion rules,
`CODE_OF_CONDUCT.md`.

## How to use it

1. Find your category in the README and scan the entries — each describes
   exactly what the free tier includes and its limits.
2. Shortlist services whose free tier fits your project, then sign up via the
   entry's link.
3. Adding a service? It must have a real free tier (not just a trial) —
   `CONTRIBUTING.md` spells out the criteria.
